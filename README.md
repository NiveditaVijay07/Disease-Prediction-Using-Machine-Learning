# Disease Prediction Using Machine Learning

## 📌 Project Overview

This project predicts the possibility of heart disease using machine learning techniques. It analyzes patient medical information and classifies whether a person is likely to have heart disease.

## 🎯 Objective

To build a classification model that predicts heart disease based on patient health data.

## 📂 Dataset

- Heart Disease Dataset
- Features include:
  - Age
  - Sex
  - Chest Pain Type
  - Blood Pressure
  - Cholesterol
  - Maximum Heart Rate
  - Other clinical measurements

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 🤖 Machine Learning Algorithm

- Random Forest Classifier

## 📊 Project Workflow

1. Import required libraries
2. Load the dataset
3. Explore and preprocess the data
4. Split features and target variable
5. Train the Random Forest model
6. Evaluate model performance
7. Generate predictions
8. Visualize results using a confusion matrix and feature importance

## 📈 Results

The trained model successfully predicts the likelihood of heart disease using patient medical data. Model performance was evaluated using accuracy and a confusion matrix.
